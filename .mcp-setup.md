# MCP Server Setup for TradeFlow

This project uses Model Context Protocol (MCP) servers to enhance Claude Code capabilities.

## Configured MCP Servers

### 1. Fetch Server
**Purpose:** Access Coinbase Advanced Trade API documentation and other web resources

**Package:** `@modelcontextprotocol/server-fetch`

**Usage:**
- Fetch Coinbase API docs: `https://docs.cloud.coinbase.com/advanced-trade-api/docs`
- Fetch any web resource for context during development

**No setup required** - works out of the box!

### 2. Notion Server
**Purpose:** Access Notion workspace for project notes, trading strategies, and documentation

**Package:** `@notionhq/mcp-server-notion`

**Setup Required:**

1. **Create a Notion Integration:**
   - Go to https://www.notion.so/my-integrations
   - Click "New integration"
   - Give it a name (e.g., "TradeFlow MCP")
   - Copy the "Internal Integration Token"

2. **Set Environment Variable:**
   ```bash
   # Add to your ~/.bashrc, ~/.zshrc, or shell config
   export NOTION_API_KEY="your_notion_integration_token_here"
   ```

3. **Share Notion Pages:**
   - Open the Notion page you want to access
   - Click "Share" → "Invite"
   - Add your integration

## Platform Compatibility

| Platform | Support | Notes |
|----------|---------|-------|
| Claude Code CLI (Desktop) | ✅ Full support | Both servers work perfectly |
| Claude Mobile Apps | ⚠️ Limited | Only if configured as remote MCP (not yet available) |
| Claude Code Web | ❌ Not supported | Known limitation - use CLI instead |

## Troubleshooting

### MCP servers not showing up?

1. **Check configuration loaded:**
   ```bash
   claude mcp list
   ```

2. **Verify .mcp.json is valid JSON:**
   ```bash
   cat .mcp.json | jq .
   ```

3. **For Notion - verify API key is set:**
   ```bash
   echo $NOTION_API_KEY
   ```

### Using in Claude Code Mobile?

Unfortunately, these local MCP servers won't work on mobile. For mobile support, you would need:
- Remote hosted MCP servers (not yet available for these tools)
- Configuration via claude.ai website

**Workaround:** Use Claude Code CLI on desktop for MCP-powered development.
